# SalesVince Website

Production website for SalesVince — ERP and Sales & Distribution software for Pakistani SMEs.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Lucide icons
- Recharts (dashboard mockup chart)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint
- `npm run typecheck` — TypeScript check
